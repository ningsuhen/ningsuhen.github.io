The interactive controls in the design system, each with a live example and the classes to use. All ship in rd.css; the research.css compatibility alias stays the frozen core. The full guide (tokens, density, colour, conformance) is at the design system.

Buttons

A .rd-btn is a keyboard-operable <button>. Variants: --primary (accent fill), --ghost (text only), --sm (compact), --icon (square, icon only). A disabled button is muted and inert.

Filter

A .rd-filter is a toggle chip: a <button> with aria-pressed. Pressed, it fills with the accent. The min-height floors at the 24px tap target.

Field

A .rd-field is a labelled control: a .rd-field__label, an .rd-input or .rd-select, and an optional .rd-field__hint (muted) or .rd-field__error (bad colour). An invalid input gets aria-invalid and a bad-colour border.

Shown when empty.

Must be a whole number.

Choice

A .rd-choice is a selectable option: a <label> wrapping a native radio (pick one) or checkbox (pick many). The native control keeps its shape; accent-color tints it with the accent. The min-height floors at the 24px tap target.

Stepper

A .rd-stepper is a value control: a minus button, a read-only value, and a plus button. The buttons are the compact icon variant (.rd-btn--icon); the value is an aria-live region so a screen reader announces each change.

Chat

A .rd-chat is a message thread. Each message is a .rd-chat__msg with a variant: --me (the user's, right-aligned and filled) and --them (the assistant's, left-aligned on the card ground). Bubbles cap at 85% so long messages wrap. The input row reuses .rd-input and .rd-btn.

Quiz

A .rd-quiz is a question with selectable options and a feedback line. The options reuse .rd-choice (labelled native radios). The feedback line uses the semantic --good / --bad colours to announce the result.

Correct — 1%.

Meter

A .rd-meter is a progress bar: a track (button ground) with a fill (accent). The fill width is set inline because it is data-driven. Give it role="progressbar" and an aria-valuenow so a screen reader can announce the value.
